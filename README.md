# CRC Project

## 📌 Description
This is a web application built using:
- Frontend: React
- Backend: Node.js

## 🚀 Features
- User login system
- Profile management
- Questions & results module

## 🛠️ Technologies Used
- JavaScript
- React
- Node.js
- Express

## ▶️ How to Run

### Frontend
cd app
npm install
npm start

### Backend
cd backend
npm install
node index.js
